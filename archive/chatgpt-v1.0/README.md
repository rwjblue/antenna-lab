# ChatGPT bundle v1.0: canonical imported model state

This directory records metadata and expected output hashes for the superseding
optimization bundle. The byte-for-byte archive is
`../source-bundles/58ft_doublet_optimization_v1.0.zip`.

v1.0 contains the completed 6,561-candidate, 390-member deterministic surrogate
ensemble. Its selected results and report are promoted under `results/` and
`reports/`. The 31 MB compact ensemble array and complete original generated
tree remain inside the ZIP to keep generated data from dominating the active
source layout.

The imported conclusions remain provisional model results, not measured facts.
