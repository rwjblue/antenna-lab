# Results policy

`reference-small/` is regenerated by the active refactored package and is small
enough for fast tests. `published-v1.0/` is retained as a legacy snapshot of
selected outputs from the earlier v1.0 optimization bundle; it is not the active
KH1 NEC-2 recommendation.

The previously checked-in `kh1-portable-nec-v1/` full result tree was removed
because it was generated by an obsolete implementation and could not be
reproduced from the active topology-aware study source.

Full KH1 NEC-2 runs are generated by the sharded GitHub Actions workflow. Each
successful run publishes the complete verified result tree as
`kh1-portable-nec-v2-<run-id>`, along with the source snapshot and every
intermediate shard. The review-corrected reference run is
[31712534336](https://github.com/rwjblue/antenna-lab/actions/runs/31712534336),
generated from commit `777bf4ddff2176db741043ec4851bee945d2fe88`; its
`SHA256SUMS` manifest passed verification.

Reproduce the full study from the checked-out source rather than relying on a
checked-in generated tree:

```bash
sudo apt-get install nec2c
uv sync --no-editable --extra plots --group dev
uv run antenna-lab run-kh1-nec-study --output build/kh1-portable-nec-v2
uv run antenna-lab verify-results build/kh1-portable-nec-v2
```

Generated scratch and full runs belong under `build/`, which is ignored by Git.
Every generated result set must contain `SHA256SUMS` and must pass
`antenna-lab verify-results`.

`kh1-portable-final-v1/` is the compact, committed decision package for the
complete 40/30/20/17/15 m KH1 system comparison. It contains derived shortlists
and finalist decompositions; the much larger NEC/tuner scenario trees remain
reproducible build artifacts whose exact input hashes are recorded in
`run_metadata.json`.
