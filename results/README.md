# Results policy

`reference-small/` is regenerated by the active refactored package and is small
enough for fast tests. `published-v1.0/` contains selected canonical outputs
copied unchanged from the superseding v1.0 ZIP.

The small grid intentionally uses fewer uncertainty scenarios and surrogate
families. Its selected 57.5/28 fixture result is a software regression value,
not a replacement for the canonical v1.0 scientific recommendation of the
reversible 57/28 experiment.

The complete v1.0 full grid and compact per-ensemble NPZ are retained in
`archive/source-bundles/58ft_doublet_optimization_v1.0.zip` rather than copied
again into the active tree. Generated scratch/full runs belong under `build/`,
which is ignored by Git.

Every active generated result set must contain `SHA256SUMS` and must pass
`antenna-lab verify-results`.
